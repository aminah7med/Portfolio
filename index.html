◉ DataPulseIn Progress

Data Quality & Pipeline Observability Platform

An extensible platform for data ingestion, quality, and incident management. Execution success does not guarantee data integrity — a pipeline can run green and still deliver stale, incomplete, or unreliable data downstream. DataPulse detects and surfaces quality issues before they affect business decisions. Already built: a Python CSV profiling tool (row counts, column metadata, encoding detection, blank values, malformed rows) with Markdown profile reports, initial schema / candidate-key / referential-integrity analysis, pytest coverage, Ruff, and GitHub Actions CI.
